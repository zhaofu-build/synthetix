# 自然语言视频剪辑/生成系统 - 方案总结

## 一、系统概述

基于自然语言交互的智能视频剪辑与生成系统，用户通过对话完成视频编辑任务。

### 核心能力
- **自然语言理解**：解析用户剪辑意图
- **多轮对话交互**：上下文记忆和追问澄清
- **视频内容理解**：多模态模型分析视频
- **智能剪辑执行**：自动生成并执行剪辑方案

## 三、核心模块设计

### 3.1 意图类型定义

| 意图类型 | 说明 | 必填槽位 |
|---------|------|---------|
| `cut_video` | 剪切视频 | video_id, start_time/end_time |
| `merge_videos` | 合并视频 | video_ids, transition(可选) |
| `add_subtitle` | 添加字幕 | video_id, subtitle_content |
| `add_audio` | 添加音频 | video_id, audio_source |
| `change_speed` | 调整速度 | video_id, speed_factor |
| `generate_video` | AI生成视频 | prompt, duration(可选) |
| `analyze_video` | 分析视频 | video_id |
| `smart_clip` | 智能剪辑 | script, style, duration |

### 3.2 对话状态机

```
┌──────┐    意图识别    ┌───────────┐    槽位完整    ┌────────────┐
│ idle │ ────────────▶ │ collecting│ ────────────▶ │ confirming │
└──────┘               └───────────┘               └────────────┘
    ▲                        │                          │
    │                        │ 槽位缺失                 │ 确认
    │                        ▼                          ▼
    │                  追问用户                   ┌───────────┐
    │                                           │ executing │
    └───────────────────────────────────────────┴───────────┘
```

### 3.3 视频理解流程

```
1. 获取视频基础信息 (duration, fps, resolution)
2. 按间隔提取关键帧 (每2秒一帧)
3. 多模态模型分析每帧:
   - 画面描述
   - 检测对象
   - 动作识别
   - 情感基调
4. 语音转写 (Whisper)
5. 生成整体描述和精彩片段建议
```

### 3.4 智能剪辑规划

```
输入: 文案 + 可用素材 + 目标时长
输出:
  - clips: 片段列表 [{source_id, start, end, purpose}]
  - transitions: 转场效果 [{type, duration}]
  - audio: 背景音乐建议
  - subtitles: 字幕时间轴
```

## 四、API 接口设计

### 4.1 对话接口

```python
POST /api/chat
Request:
{
    "session_id": "可选，用于多轮对话",
    "message": "帮我把视频前30秒剪出来"
}

Response:
{
    "session_id": "uuid",
    "reply": "好的，请告诉我要剪辑哪个视频？",
    "status": "collecting",  # idle/collecting/confirming/executing
    "suggestions": ["旅行记录.mp4", "产品演示.mp4"]
}
```

### 4.2 WebSocket 实时对话

```python
WS /api/ws/chat
# 实时双向通信，支持流式响应
```

### 4.3 直接执行接口

```python
POST /api/execute
{
    "tool": "cut_video",
    "params": {
        "video_path": "/path/to/video.mp4",
        "start_time": "00:00:00",
        "end_time": "00:00:30"
    }
}
```

## 五、对话流程示例

### 示例1：简单剪辑

```
用户: 帮我把视频前30秒剪出来
助手: 好的，请告诉我要剪辑哪个视频？

用户: 旅行记录.mp4
助手: 确认以下操作：
      - 视频：旅行记录.mp4 (5分钟)
      - 时间：00:00:00 - 00:00:30
      确认吗？

用户: 确认
助手: [执行中...] 完成！
      输出：/static/uploads/旅行记录_剪辑.mp4
```

### 示例2：智能混剪

```
用户: 帮我做一个30秒的旅行Vlog混剪，要燃一点
助手: 分析素材中...找到5个相关视频

      剪辑方案：
      - 开场：海边日出慢动作 (5秒)
      - 过渡：城市街景快切 (8秒)
      - 高潮：跳伞+冲浪 (12秒)
      - 收尾：夕阳剪影 (5秒)

      背景音乐：电子乐 128bpm
      确认执行？

用户: 把跳伞换成潜水
助手: 已更新方案，确认？

用户: 好的
助手: [执行中...] 混剪完成！
```

### 示例3：AI生成视频

```
用户: 生成一段15秒日落海滩视频
助手: 请补充细节：
      - 风格：写实/动漫/电影感？
      - 时间：黄金时刻/蓝调时刻？

用户: 电影感，黄金时刻
助手: 生成参数：
      - 内容：日落海滩，黄金时刻
      - 时长：15秒，风格：电影感
      开始生成？

用户: 开始
助手: [生成中...35%...100%]
      完成！/static/generated/sunset_15s.mp4
```
