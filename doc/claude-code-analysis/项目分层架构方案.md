# 多项目分层架构方案

## 一、整体架构：三个项目，两层依赖

```
┌──────────────────────────────────────────────────────────────────────┐
│                         业务应用层                                    │
│                                                                      │
│   ┌──────────────┐  ┌────────────────┐  ┌──────────┐  ┌──────────┐ │
│   │  synthetix   │  │    carla       │  │ 个人助手  │  │ 未来项目  │ │
│   │  视频剪辑    │  │   数字人对话    │  │          │  │  ...     │ │
│   │ （Agent 模式）│  │（LLMClient 模式）│  │          │  │          │ │
│   └──────┬───────┘  └───────┬────────┘  └────┬─────┘  └────┬─────┘ │
│          │                  │                 │               │       │
│          │ 使用框架全部模块   │ 只用 LLMClient  │               │       │
│          │ 9/9              │ + AgentConfig   │               │       │
│          │                  │ 2/9            │               │       │
│          └──────────┬───────┴────────────────┴───────────────┘       │
│                     │ pip install                                     │
├─────────────────────┼────────────────────────────────────────────────┤
│                     ▼                                                │
│           ai-agent-framework（pip 包）                                │
│                                                                      │
│  Agent / 工具 / 意图 / 槽位 / 会话 / 记忆 / Prompt                    │
│  + 内置 LLM 客户端（直连 core-nexus-ai）                               │
│                     │                                                │
│                     │ HTTP                                            │
├─────────────────────┼────────────────────────────────────────────────┤
│                     ▼                                                │
│           core-nexus-ai（独立服务，端口 9666）                          │
│           LLM / TTS / ASR / VL / OCR / 文生图 / 文生视频 / 音乐       │
└──────────────────────────────────────────────────────────────────────┘
```

**核心思路**：框架自带 LLM 调用能力（直连 core-nexus-ai），业务项目只需配置地址和模型。

**两种使用模式**：
- **Agent 模式**（synthetix / 个人助手）：使用框架全部 9 个模块，适合「意图→槽位→确认→执行」的工具型应用
- **LLMClient 模式**（carla）：只使用 `LLMClient` + `AgentConfig`，适合自由对话型应用，替换自己的 HTTP 调用层

## 二、各层职责

### 第 1 层：core-nexus-ai — 大模型推理服务

```
是什么：独立部署的后端服务（已有，Python FastAPI）
做什么：只做 AI 推理，不管业务
端口：默认 9666
```

| 能力 | API 端点 | 说明 |
|------|----------|------|
| LLM | `POST /llm` | 大语言模型生成（流式: `POST /llm/stream`） |
| TTS | `POST /tts` | 文字转语音 |
| ASR | `POST /asr` | 语音转文字 |
| VL | `POST /vl` | 图片/视频理解 |
| OCR | `POST /ocr` | 文字识别 |
| 文生图 | `POST /text-to-image` | 文本生成图像 |
| 文生视频 | `POST /text-to-video` | 文本生成视频 |
| 音乐 | `POST /text-to-music` | 音乐生成 |
| 多模态 | `POST /multimodal` | 多模态对话 |

**请求格式**（以 LLM 为例）：
```json
// POST /llm
{ "messages": [{"role": "user", "content": "..."}],
  "model": "qwen-plus",              // 可选，不传用数据库默认
  "generation": {
      "temperature": 0.7,
      "max_tokens": 2048
  }
}

// 响应
{ "output": {"text": "..."},
  "model": "qwen-plus",
  "usage": {"prompt_tokens": 100, "completion_tokens": 200} }
```

**不管什么是视频剪辑、日程管理**，只负责调模型返回结果。core-nexus-ai 本身不需要改造，框架的 LLMClient 来适配它的接口。

---

### 第 2 层：ai-agent-framework — Agent 通用框架（pip 包）

```
是什么：一个 pip 包，从 synthetix 现有代码提取
做什么：提供构建 AI Agent 的全部通用能力
怎么调模型：内置 LLM 客户端，直连 core-nexus-ai
怎么配置：业务项目传入 AgentConfig（地址 + 模型映射）
```

提供 9 个模块（按使用模式分组）：

**通用模块**（所有项目都可用）：

| 模块 | 做什么 |
|------|--------|
| **AgentConfig** | 配置（core-nexus-ai 地址、各任务用什么模型） |
| **LLMClient** | 内置客户端（调 core-nexus-ai 的 LLM/TTS/ASR/VL），按 `task` 自动选模型 |

**Agent 模块**（工具执行型应用用）：

| 模块 | 做什么 |
|------|--------|
| ToolRegistry | 工具注册 `@registry.register()` |
| BaseAgent | Agent 基类，状态机编排（IDLE→COLLECTING→CONFIRMING→EXECUTING） |
| IntentRecognizer | 意图识别（规则匹配 + LLM） |
| SlotFiller | 槽位填充（正则提取 + LLM） |
| SessionManager | 会话管理（创建/获取/过期清理） |

**辅助模块**：

| 模块 | 做什么 |
|------|--------|
| PromptManager | Prompt 模板管理（简单 KV，复杂管线项目可不用） |
| Memory | 记忆系统（短期内存 + 长期文件，适合轻量场景） |

### 第 3 层：业务应用 — 各自写各自的

**Agent 模式项目**（如 synthetix、个人助手）只需写四样东西：
1. **AgentConfig** — 配置 core-nexus-ai 地址 + 各任务用什么模型
2. **工具** — cut_video、send_email 等业务函数
3. **意图和槽位** — 领域相关的定义
4. **Prompt** — 角色、能力描述

**LLMClient 模式项目**（如 carla）更简单：
1. **AgentConfig** — 配置 core-nexus-ai 地址 + 模型
2. **封装 LLMService** — 内部用框架的 `LLMClient` 替换原有 HTTP 调用，对外接口不变

> carla 是自由对话型数字人系统（角色扮演 + 情绪 + 记忆 + 世界观），不做意图→槽位→执行，因此不使用框架的 Agent/Intent/Slot 模块。

## 三、核心设计：AgentConfig 配置

框架内置 LLM 客户端，业务项目通过配置告诉框架：
- core-nexus-ai 在哪（`base_url`）
- 每种任务用什么模型（`models`）

```python

### 4.1 config.py — 配置

```python
"""Agent 配置"""
from typing import Dict, Optional
from dataclasses import dataclass, field


@dataclass
class AgentConfig:
    """Agent 配置

    用法：
        config = AgentConfig(
            base_url="http://192.168.1.100:9666",
            models={"default": "qwen-plus", "intent": "qwen-turbo", "chat": "qwen-max"},
        )
    """

    # core-nexus-ai 服务地址（默认端口 9666）
    base_url: str = "http://localhost:9666"

    # 各任务使用的模型
    # key = task 名称，value = 模型名称
    # 支持的 task：default, intent, slot, chat, planning, creative
    models: Dict[str, str] = field(default_factory=lambda: {"default": "qwen-plus"})

    # 全局默认参数
    temperature: float = 0.7
    max_tokens: int = 2048

    # core-nexus-ai API Key（如果需要）
    api_key: Optional[str] = None

    def get_model(self, task: str) -> str:
        """获取指定任务的模型名"""
        return self.models.get(task, self.models.get("default", "qwen-plus"))

### 4.2 client.py — LLM 客户端（直连 core-nexus-ai）

从现有 `src/shared/utils/core_nexus_client.py` 提取，精简为框架内部的客户端：

```python
"""LLM 客户端 — 直连 core-nexus-ai"""
import json
import httpx
import logging
from typing import List, Dict, Optional, Any, AsyncGenerator

from ai_agent.config import AgentConfig

logger = logging.getLogger(__name__)


class LLMClient:
    """直连 core-nexus-ai 的客户端

    业务项目可通过 AgentConfig 配置，也可以直接使用此类（如 carla）。
    """

    def __init__(self, config: AgentConfig):
        self.config = config
        self.base_url = config.base_url.rstrip("/")
        self.api_key = config.api_key

    # ---- LLM 文本生成 ----

    async def generate(
        self,
        messages: List[Dict[str, str]],
        task: str = "default",
        model: str = None,
        temperature: float = None,
        max_tokens: int = None,
    ) -> str:
        """LLM 文本生成（非流式）

        Args:
            messages: 对话消息列表
            task: 任务类型（自动选模型），如 "intent"、"slot"、"chat"
            model: 手动指定模型（优先级高于 task）
            temperature: 温度
            max_tokens: 最大 token 数
        """
        actual_model = model or self.config.get_model(task)
        actual_temp = temperature or self.config.temperature
        actual_max = max_tokens or self.config.max_tokens

        async with httpx.AsyncClient(timeout=120) as client:
            resp = await client.post(
                f"{self.base_url}/llm",
                json={
                    "messages": messages,
                    "model": actual_model,
                    "generation": {
                        "temperature": actual_temp,
                        "max_tokens": actual_max,
                    },
                },
                headers=self._headers(),
            )
            resp.raise_for_status()
            return resp.json()["output"]["text"]

    async def generate_stream(
        self,
        messages: List[Dict[str, str]],
        task: str = "default",
        model: str = None,
        temperature: float = None,
        max_tokens: int = None,
    ) -> AsyncGenerator[str, None]:
        """LLM 流式生成"""
        actual_model = model or self.config.get_model(task)
        actual_temp = temperature or self.config.temperature
        actual_max = max_tokens or self.config.max_tokens

        async with httpx.AsyncClient(timeout=120) as client:
            async with client.stream(
                "POST",
                f"{self.base_url}/llm/stream",
                json={
                    "messages": messages,
                    "model": actual_model,
                    "generation": {
                        "temperature": actual_temp,
                        "max_tokens": actual_max,
                    },
                },
                headers=self._headers(),
            ) as resp:
                async for line in resp.aiter_lines():
                    if line.startswith("data: "):
                        chunk = line[6:]
                        if chunk.strip() == "[DONE]":
                            break
                        try:
                            data = json.loads(chunk)
                            yield data["output"]["text"]
                        except (json.JSONDecodeError, KeyError):
                            continue

    # ---- TTS 语音合成 ----

    async def tts(self, text: str, speaker_id: int = None, **kwargs) -> str:
        """文字转语音，返回音频（data URL 或路径）"""
        payload = {"text": text, **kwargs}
        if speaker_id is not None:
            payload["speaker"] = str(speaker_id)

        async with httpx.AsyncClient(timeout=120) as client:
            resp = await client.post(
                f"{self.base_url}/tts",
                json=payload,
                headers=self._headers(),
            )
            resp.raise_for_status()
            return resp.json()["output"].get("audio", "")

    # ---- ASR 语音识别 ----

    async def asr(self, audio_path: str = None, audio: str = None, **kwargs) -> str:
        """语音转文字"""
        payload = {**kwargs}
        if audio_path:
            payload["audio"] = audio_path
        elif audio:
            payload["audio"] = audio

        async with httpx.AsyncClient(timeout=120) as client:
            resp = await client.post(
                f"{self.base_url}/asr",
                json=payload,
                headers=self._headers(),
            )
            resp.raise_for_status()
            return resp.json()["output"].get("text", "")

    # ---- VL 视觉理解 ----

    async def vl(self, image_path: str = None, image_url: str = None, prompt: str = "", **kwargs) -> str:
        """图片/视频理解"""
        payload = {"prompt": prompt, **kwargs}
        if image_path:
            payload["image"] = image_path
        if image_url:
            payload["image"] = image_url

        async with httpx.AsyncClient(timeout=120) as client:
            resp = await client.post(
                f"{self.base_url}/vl",
                json=payload,
                headers=self._headers(),
            )
            resp.raise_for_status()
            return resp.json()["output"].get("text", "")

    # ---- 工具方法 ----

    def _headers(self) -> Dict[str, str]:
        headers = {"Content-Type": "application/json"}
        if self.api_key:
            headers["Authorization"] = f"Bearer {self.api_key}"
        return headers
```

**API 路径映射**（已对齐 core-nexus-ai 实际接口）：

| 框架方法 | core-nexus-ai 端点 |
|----------|-------------------|
| `generate()` | `POST /llm` |
| `generate_stream()` | `POST /llm/stream` |
| `tts()` | `POST /tts` |
| `asr()` | `POST /asr` |
| `vl()` | `POST /vl` |

**请求格式要点**：
- `temperature`、`max_tokens` 必须嵌套在 `generation` 对象中
- 不传 `model` 时 core-nexus-ai 自动使用数据库默认模型
- 响应从 `output.text` / `output.audio` 提取

### 4.3 tool_registry.py — 工具注册表

从现有 `src/agent/tool_registry.py` 提取，**去掉所有视频工具**，只保留框架：

```python
"""工具注册表"""
import logging
from typing import Dict, List, Optional, Callable, Any
from dataclasses import dataclass, field

logger = logging.getLogger(__name__)


@dataclass
class Tool:
    """工具定义"""
    name: str
    description: str
    parameters: Dict[str, Any]
    execute: Callable
    examples: List[str] = field(default_factory=list)


class ToolRegistry:
    """工具注册表"""

    def __init__(self):
        self._tools: Dict[str, Tool] = {}

    def register(
        self,
        name: str,
        description: str,
        parameters: Dict[str, Any],
        examples: List[str] = None
    ) -> Callable:
        """装饰器：注册工具"""
        def decorator(func: Callable):
            self._tools[name] = Tool(
                name=name, description=description,
                parameters=parameters, execute=func,
                examples=examples or [],
            )
            logger.info(f"注册工具: {name}")
            return func
        return decorator

    def register_tool(self, tool: Tool):
        self._tools[tool.name] = tool

    def get_tool(self, name: str) -> Optional[Tool]:
        return self._tools.get(name)

    def list_tools(self) -> List[Tool]:
        return list(self._tools.values())

    def get_tools_description(self) -> str:
        """生成工具描述（供 Prompt 使用）"""
        lines = []
        for tool in self._tools.values():
            params = ", ".join(f"{k}: {v['description']}" for k, v in tool.parameters.items())
            lines.append(f"- {tool.name}: {tool.description}\n  参数: {params}")
        return "\n".join(lines)

    def has_tool(self, name: str) -> bool:
        return name in self._tools
```

### 4.4 session.py — 会话管理

从现有代码提取，`current_video_id` 改为通用 `context` 字典：

```python
"""会话管理"""
import uuid
import time
from typing import Dict, List, Optional, Any
from dataclasses import dataclass, field
from enum import Enum


class SessionStatus(Enum):
    IDLE = "idle"
    COLLECTING = "collecting"
    CONFIRMING = "confirming"
    EXECUTING = "executing"
    COMPLETED = "completed"
    ERROR = "error"


@dataclass
class DialogState:
    session_id: str
    status: SessionStatus = SessionStatus.IDLE
    intent: Optional[str] = None
    slots: Dict[str, Any] = field(default_factory=dict)
    history: List[Dict[str, str]] = field(default_factory=list)
    pending_action: Optional[Dict[str, Any]] = None
    context: Dict[str, Any] = field(default_factory=dict)   # 通用上下文
    created_at: float = field(default_factory=time.time)
    updated_at: float = field(default_factory=time.time)
    metadata: Dict[str, Any] = field(default_factory=dict)

    def add_message(self, role: str, content: str):
        self.history.append({"role": role, "content": content})
        self.updated_at = time.time()

    def get_context_messages(self, limit: int = 5) -> List[Dict[str, str]]:
        return self.history[-limit:] if self.history else []

    def reset(self):
        self.status = SessionStatus.IDLE
        self.intent = None
        self.slots = {}
        self.pending_action = None
        self.updated_at = time.time()


class SessionManager:
    def __init__(self, session_timeout: int = 3600):
        self._sessions: Dict[str, DialogState] = {}
        self._session_timeout = session_timeout

    def create_session(self, session_id: Optional[str] = None) -> DialogState:
        sid = session_id or str(uuid.uuid4())
        state = DialogState(session_id=sid)
        self._sessions[sid] = state
        return state

    def get_session(self, session_id: str) -> Optional[DialogState]:
        session = self._sessions.get(session_id)
        if session:
            session.updated_at = time.time()
        return session

    def get_or_create_session(self, session_id: Optional[str] = None) -> DialogState:
        if session_id:
            session = self.get_session(session_id)
            if session:
                return session
        return self.create_session(session_id)

    def delete_session(self, session_id: str) -> bool:
        if session_id in self._sessions:
            del self._sessions[session_id]
            return True
        return False

    def cleanup_expired_sessions(self) -> int:
        now = time.time()
        expired = [sid for sid, s in self._sessions.items() if now - s.updated_at > self._session_timeout]
        for sid in expired:
            del self._sessions[sid]
        return len(expired)
```

### 4.5 intent.py — 意图识别

与之前版本的区别：用 `LLMClient` 替代 `llm_fn`，调 LLM 时传 `task="intent"`：

```python
"""意图识别"""
import json
import logging
from typing import Dict, List, Optional, Any
from dataclasses import dataclass, field

from ai_agent.client import LLMClient

logger = logging.getLogger(__name__)


@dataclass
class IntentResult:
    intent: str
    confidence: float
    entities: Dict[str, Any]
    need_clarification: bool
    clarification_question: str

    @classmethod
    def from_dict(cls, data: Dict) -> "IntentResult":
        return cls(
            intent=data.get("intent", "unknown"),
            confidence=data.get("confidence", 0.0),
            entities=data.get("entities", {}),
            need_clarification=data.get("need_clarification", False),
            clarification_question=data.get("clarification_question", ""),
        )


@dataclass
class IntentDefinition:
    name: str
    description: str
    slots: List[str]
    required_slots: List[str]
    keywords: List[str] = field(default_factory=list)


class IntentRecognizer:
    def __init__(
        self,
        intents: Dict[str, IntentDefinition],
        llm: LLMClient,                              # ← 框架内置客户端
        intent_prompt_template: str = None,
        quick_match_rules: Dict[str, List[str]] = None,
    ):
        self.intents = intents
        self.llm = llm
        self.prompt_template = intent_prompt_template or self._default_template()
        self.quick_match_rules = quick_match_rules or {
            name: intent.keywords for name, intent in intents.items() if intent.keywords
        }

    async def recognize(self, user_input: str, history: List[Dict] = None, context: Dict = None) -> IntentResult:
        quick = self._quick_match(user_input)
        if quick:
            return quick
        return await self._llm_recognize(user_input, history or [], context or {})

    def _quick_match(self, text: str) -> Optional[IntentResult]:
        t = text.lower().strip()
        if t in ["确认", "好的", "可以", "是", "执行", "确定", "ok", "yes"]:
            return IntentResult("confirm", 1.0, {}, False, "")
        if t in ["取消", "不要", "不行", "否", "算了", "cancel", "no"]:
            return IntentResult("cancel", 1.0, {}, False, "")
        if t in ["帮助", "help", "怎么用", "你能做什么"]:
            return IntentResult("help", 1.0, {}, False, "")
        for name, keywords in self.quick_match_rules.items():
            if any(kw in t for kw in keywords):
                return IntentResult(name, 0.9, {}, False, "")
        return None

    async def _llm_recognize(self, user_input, history, context) -> IntentResult:
        prompt = self.prompt_template.format(
            user_input=user_input,
            history=str(history[-3:]),
            context=str(context),
            intents="\n".join(f"- {n}: {i.description}" for n, i in self.intents.items()),
        )
        try:
            response = await self.llm.generate(
                messages=[{"role": "user", "content": prompt}],
                task="intent",                        # ← 自动用 config.models["intent"] 指定的模型
            )
            response = response.strip()
            if response.startswith("```"):
                response = response.split("\n", 1)[1]
            if response.endswith("```"):
                response = response.rsplit("```", 1)[0]
            return IntentResult.from_dict(json.loads(response))
        except Exception as e:
            logger.error(f"意图识别失败: {e}")
            return IntentResult("unknown", 0.0, {}, True, "抱歉，我没理解。请描述得更具体一些？")

    def _default_template(self) -> str:
        return """分析用户意图。

用户输入：{user_input}
对话历史：{history}
上下文：{context}

可选意图：
{intents}
- help: 获取帮助
- unknown: 无法识别

返回 JSON（不要 ```json 标记）：
{{"intent": "意图名", "confidence": 0.95, "entities": {{}}, "need_clarification": false, "clarification_question": ""}}"""

    def get_intent_info(self, name: str) -> Optional[IntentDefinition]:
        return self.intents.get(name)

    def get_required_slots(self, name: str) -> List[str]:
        info = self.intents.get(name)
        return info.required_slots if info else []
```

### 4.6 slot.py — 槽位填充

同样用 `LLMClient`，调 LLM 时传 `task="slot"`：

```python
"""槽位填充"""
import json
import logging
from typing import Dict, List, Optional, Any, Callable
from dataclasses import dataclass

from ai_agent.client import LLMClient

logger = logging.getLogger(__name__)


@dataclass
class SlotDefinition:
    name: str
    description: str
    required: bool = True
    default: Any = None
    prompt: str = ""
    extract_rule: Callable = None       # 自定义提取函数


class SlotFiller:
    def __init__(self, slots: Dict[str, SlotDefinition], llm: LLMClient, slot_prompt_template: str = None):
        self.slots = slots
        self.llm = llm
        self.prompt_template = slot_prompt_template or self._default_template()

    async def fill(self, user_input: str, slot_names: List[str], filled_slots: Dict[str, Any]) -> Dict[str, Any]:
        unfilled = [n for n in slot_names if n not in filled_slots]
        if not unfilled:
            return {}

        # 1. 自定义规则提取
        result = {}
        for name in unfilled:
            slot = self.slots.get(name)
            if slot and slot.extract_rule:
                value = slot.extract_rule(user_input)
                if value is not None:
                    result[name] = value
        if result:
            return result

        # 2. LLM 提取
        return await self._llm_extract(user_input, unfilled, filled_slots)

    async def _llm_extract(self, user_input, slot_names, filled_slots) -> Dict[str, Any]:
        descriptions = {n: self.slots[n].description for n in slot_names if n in self.slots}
        prompt = self.prompt_template.format(
            user_input=user_input,
            slot_names=descriptions,
            filled_slots=filled_slots,
        )
        try:
            response = await self.llm.generate(
                messages=[{"role": "user", "content": prompt}],
                task="slot",                            # ← 自动用 config.models["slot"] 指定的模型
            )
            response = response.strip()
            if response.startswith("```"):
                response = response.split("\n", 1)[1]
            if response.endswith("```"):
                response = response.rsplit("```", 1)[0]
            return json.loads(response)
        except Exception as e:
            logger.error(f"槽位提取失败: {e}")
            return {}

    def get_missing_slots(self, required: List[str], filled: Dict[str, Any]) -> List[SlotDefinition]:
        missing = []
        for name in required:
            if name not in filled or filled[name] is None:
                missing.append(self.slots.get(name, SlotDefinition(name, name, prompt=f"请提供 {name}")))
        return missing

    def _default_template(self) -> str:
        return """从用户输入中提取字段。

用户输入：{user_input}
需要提取：{slot_names}
已填充：{filled_slots}

返回 JSON（不要 ```json 标记）：
{{"字段名": "提取的值"}}
注意：只返回能明确提取的，无法提取则不返回。"""
```

### 4.7 agent.py — Agent 基类

**关键变化**：构造函数接收 `AgentConfig` 而不是 `llm_fn`，内部创建 `LLMClient`：

```python
"""Agent 基类"""
import logging
from typing import Dict, List, Optional, Any

from ai_agent.config import AgentConfig
from ai_agent.client import LLMClient
from ai_agent.core.session import SessionManager, SessionStatus, DialogState
from ai_agent.core.intent import IntentRecognizer, IntentDefinition, IntentResult
from ai_agent.core.slot import SlotFiller, SlotDefinition
from ai_agent.core.tool_registry import ToolRegistry

logger = logging.getLogger(__name__)


class BaseAgent:
    """Agent 基类

    子类只需实现：
        - format_confirmation(action)  → 确认消息格式
        - get_help_text()              → 帮助文本
        - （可选）auto_fill_slots       → 自动填充槽位

    用法：
        class VideoAgent(BaseAgent):
            def format_confirmation(self, action): ...
            def get_help_text(self): ...

        agent = VideoAgent(
            config=AgentConfig(base_url="http://...", models={...}),
            intents={...},
            slots={...},
            registry=registry,
        )
        result = await agent.process_message(session_id, "帮我把视频前30秒剪出来")
    """

    def __init__(
        self,
        config: AgentConfig,
        intents: Dict[str, IntentDefinition],
        slots: Dict[str, SlotDefinition],
        registry: ToolRegistry,
        session_timeout: int = 3600,
        intent_prompt_template: str = None,
        slot_prompt_template: str = None,
        quick_match_rules: Dict[str, List[str]] = None,
    ):
        self.config = config
        self.llm = LLMClient(config)                    # ← 框架内置客户端
        self.registry = registry
        self.sessions = SessionManager(session_timeout=session_timeout)

        self.intents = IntentRecognizer(
            intents=intents,
            llm=self.llm,                               # ← 传客户端
            intent_prompt_template=intent_prompt_template,
            quick_match_rules=quick_match_rules,
        )
        self.slots = SlotFiller(
            slots=slots,
            llm=self.llm,                               # ← 传客户端
            slot_prompt_template=slot_prompt_template,
        )

    async def process_message(
        self,
        session_id: Optional[str],
        user_input: str,
        context: Optional[Dict] = None,
    ) -> Dict[str, Any]:
        """处理用户消息（主入口）"""
        state = self.sessions.get_or_create_session(session_id)
        state.add_message("user", user_input)
        if context:
            state.context.update(context)

        try:
            handlers = {
                SessionStatus.IDLE: self._handle_idle,
                SessionStatus.COLLECTING: self._handle_collecting,
                SessionStatus.CONFIRMING: self._handle_confirming,
            }
            handler = handlers.get(state.status, self._handle_idle)
            result = await handler(state, user_input)
        except Exception as e:
            logger.error(f"处理消息失败: {e}", exc_info=True)
            state.status = SessionStatus.ERROR
            result = {"reply": f"处理出错: {e}", "status": "error"}

        state.add_message("assistant", result.get("reply", ""))
        result["session_id"] = state.session_id
        return result

    # ---- 状态机 ----

    async def _handle_idle(self, state, user_input):
        intent_result = await self.intents.recognize(user_input, state.history, state.context)
        logger.info(f"意图: {intent_result.intent}, 置信度: {intent_result.confidence}")

        if intent_result.intent == "confirm":
            return {"reply": "当前没有待执行的操作。请告诉我您想做什么？", "status": "idle"}
        if intent_result.intent == "cancel":
            state.reset()
            return {"reply": "操作已取消。", "status": "idle"}
        if intent_result.intent == "help":
            return {"reply": self.get_help_text(), "status": "idle"}
        if intent_result.need_clarification:
            return {"reply": intent_result.clarification_question, "status": "idle"}
        if intent_result.intent == "unknown":
            return {"reply": self.get_unknown_intent_reply(), "status": "idle"}

        custom = await self.handle_custom_intent(intent_result, state)
        if custom:
            return custom

        state.intent = intent_result.intent
        state.slots = intent_result.entities.copy()
        state.status = SessionStatus.COLLECTING
        return await self._handle_collecting(state, user_input)

    async def _handle_collecting(self, state, user_input):
        intent_info = self.intents.get_intent_info(state.intent)
        if not intent_info:
            state.reset()
            return {"reply": "未知意图，请重新描述。", "status": "idle"}

        new_slots = await self.slots.fill(user_input, intent_info.slots, state.slots)
        state.slots.update(new_slots)
        await self.auto_fill_slots(state, intent_info)

        missing = self.slots.get_missing_slots(intent_info.required_slots, state.slots)
        if missing:
            return {"reply": missing[0].prompt, "status": "collecting", "missing_slots": [s.name for s in missing]}

        action = {"tool": state.intent, "params": state.slots.copy()}
        state.pending_action = action
        state.status = SessionStatus.CONFIRMING
        return {"reply": self.format_confirmation(action), "status": "confirming", "action": action}

    async def _handle_confirming(self, state, user_input):
        text = user_input.lower().strip()

        if text in ["确认", "好的", "可以", "是", "执行", "确定", "ok", "yes"]:
            state.status = SessionStatus.EXECUTING
            result = await self._execute_action(state.pending_action)
            ok = result.get("success")
            if ok:
                state.status = SessionStatus.COMPLETED
            else:
                state.status = SessionStatus.ERROR
            state.reset()
            prefix = "✅" if ok else "❌"
            msg = result.get("message", "操作完成") if ok else result.get("error", "未知错误")
            return {"reply": f"{prefix} {msg}", "status": "completed" if ok else "error", "result": result}

        if text in ["取消", "不要", "不行", "否", "算了", "cancel", "no"]:
            state.reset()
            return {"reply": "操作已取消。", "status": "idle"}

        state.status = SessionStatus.COLLECTING
        return await self._handle_collecting(state, user_input)

    async def _execute_action(self, action):
        tool = self.registry.get_tool(action["tool"])
        if not tool:
            return {"success": False, "error": f"未知工具: {action['tool']}"}
        try:
            return await tool.execute(**action["params"])
        except Exception as e:
            return {"success": False, "error": str(e)}

    # ---- 子类覆盖 ----

    def format_confirmation(self, action: Dict) -> str:
        return f"请确认：{action['tool']} {action['params']}\n回复 **确认** 执行。"

    def get_help_text(self) -> str:
        return f"我可以帮你：\n{self.registry.get_tools_description()}"

    def get_unknown_intent_reply(self) -> str:
        return "抱歉，我没理解。请描述您想做什么。"

    async def handle_custom_intent(self, intent_result, state) -> Optional[Dict]:
        return None

    async def auto_fill_slots(self, state, intent_info):
        pass
```

### 4.9 memory/memory.py — 记忆系统

"""记忆系统 — 短期（内存）+ 长期（文件）"""
import json
import time
from typing import Dict, List, Optional, Any
from pathlib import Path


class Memory:
    def __init__(self, storage_dir: str = ".ai_memory"):
        self._cache: Dict[str, Any] = {}
        self._max_cache = 100
        self._dir = Path(storage_dir)
        self._dir.mkdir(parents=True, exist_ok=True)

    def save(self, key: str, value: Any):
        if len(self._cache) >= self._max_cache:
            self._cache.pop(next(iter(self._cache)))
        self._cache[key] = {"value": value, "ts": time.time()}

    def load(self, key: str) -> Optional[Any]:
        entry = self._cache.get(key)
        return entry["value"] if entry else None

    def persist(self, key: str, value: Any):
        path = self._dir / f"{key}.json"
        path.write_text(json.dumps({"value": value, "ts": time.time()}, ensure_ascii=False, indent=2))

    def load_persistent(self, key: str) -> Optional[Any]:
        path = self._dir / f"{key}.json"
        if path.exists():
            return json.loads(path.read_text(encoding="utf-8")).get("value")
        return None

    def save_session(self, session_id: str, messages: List[Dict]):
        path = self._dir / "sessions" / f"{session_id}.json"
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_text(json.dumps(messages, ensure_ascii=False, indent=2))

    def load_session(self, session_id: str) -> List[Dict]:
        path = self._dir / "sessions" / f"{session_id}.json"
        return json.loads(path.read_text(encoding="utf-8")) if path.exists() else []

from typing import Generic, TypeVar, Optional, List, Any
from pydantic import BaseModel, Field
from datetime import datetime

T = TypeVar('T')

class APIResponse(BaseModel, Generic[T]):
    success: bool = True
    data: Optional[T] = None
    message: str = ""
    code: int = 200
    timestamp: int = Field(default_factory=lambda: int(datetime.now().timestamp()))

def success_response(data=None, message="操作成功", to_camel=True):
    if to_camel and data and isinstance(data, dict):
        data = _to_camel(data)
    return APIResponse(success=True, data=data, message=message)

def error_response(error: str, message: str, code: int = 500):
    return {"success": False, "error": error, "message": message, "code": code}

def _to_camel(d: dict) -> dict:
    return {''.join(w.capitalize() if i else w for i, w in enumerate(k.split('_'))): v for k, v in d.items()}

from ai_agent import LLMClient
from src.agent_config import config

_client = LLMClient(config)


class LLMService:
    """封装框架 LLMClient，对外接口不变"""

    async def generate(self, messages, temperature=0.8, max_tokens=2000, model=None):
        text = await _client.generate(
            messages=messages, task="chat",
            model=model, temperature=temperature, max_tokens=max_tokens,
        )
        return {"text": text, "model": model or config.get_model("chat"), "usage": {}}

    async def stream(self, messages, temperature=0.8, max_tokens=2000, model=None):
        async for chunk in _client.generate_stream(
            messages=messages, task="chat",
            model=model, temperature=temperature, max_tokens=max_tokens,
        ):
            yield chunk
