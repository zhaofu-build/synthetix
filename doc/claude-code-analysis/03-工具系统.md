# 03 - 工具系统

## 概述

工具系统是 Claude Code 实现从"回答器"到"执行体"质变的关键。包含 40+ 内置工具，通过**标准化接口**、**安全隔离**和**多级验证**，确保 AI 能安全有效地执行各类开发操作。所有工具遵循 Unix 哲学："每个工具都做好一件事"。

## 工具接口定义

所有工具都基于 `ToolBase` 抽象类实现，定义了统一的生命周期：

```typescript
interface Tool {
  // 基础信息
  name: string;                    // 工具内部名称
  userFacingName(): string;        // 显示给用户的名称
  description: string;             // 工具描述

  // 参数定义
  inputSchema: z.ZodType;          // 输入参数 Zod Schema（运行时校验）

  // 权限声明
  isDangerous: boolean;            // 是否高危
  requiresConfirmation: boolean;   // 是否需确认
  executionType: 'readonly' | 'stateful' | 'dangerous';

  // 执行逻辑
  execute(params, context): Promise<ToolResult>;

  // 可选：UI 渲染
  renderToolUseMessage?: (input) => string;      // 渲染工具调用信息
  renderToolResultMessage?: (output) => string;   // 渲染工具结果信息
}
```

### 以 ReadTool 为例

```typescript
class ReadTool implements Tool {
  name = "Read";
  description = "读取文件内容，支持代码、图片、PDF等格式";
  inputSchema = z.object({
    path: z.string({ required: true }),
    offset: z.number({ min: 0 }).optional(),
    limit: z.number({ min: 1, max: 10000 }).optional()
  });

  async execute(params: any, context: Context): Promise<ToolResult> {
    const validatedParams = this.inputSchema.parse(params);  // Zod 校验
    const content = await fs.readFile(validatedParams.path, 'utf8');
    // 大文件截断处理
    if (content.length > validatedParams.limit!) {
      return { type: 'tool_result', result: { content: content.substr(...), truncated: true } };
    }
    return { type: 'tool_result', result: { content, truncated: false } };
  }
}
```

## 执行策略

### 并行执行（只读工具）

```typescript
// 只读工具并行执行
if (allToolsAreReadOnly(toolCalls)) {
  for await (const message of runToolsConcurrently(toolCalls)) { ... }
}
```

- 使用 `Promise.allSettled` 实现真正并行
- Read、Grep、Glob、WebSearch 等只读工具自动并行
- 单轮最多并行发出约 10 个工具调用

### 串行执行（高危工具）

```typescript
// 高危工具串行执行
else {
  for await (const message of runToolsSerially(toolCalls)) { ... }
}
```

- Bash、Edit、Write 等高危工具必须串行
- 需用户确认的工具通过 `requestConfirmationFromUser` 弹窗确认

## 工具注册流程

### 内置工具注册

```typescript
const builtInTools = new Map<string, Tool>();

function registerBuiltInTools() {
  // 文件操作
  builtInTools.set("Read", new ReadTool());
  builtInTools.set("Write", new WriteTool());
  builtInTools.set("Edit", new EditTool());
  builtInTools.set("Glob", new GlobTool());
  // ... 40+ 工具
}
```

### 工具管理器

```typescript
class ToolManager {
  private tools: Map<string, Tool>;
  private availableTools: Map<string, Tool>;
  private permissionManager: PermissionManager;

  // 根据权限过滤可用工具
  filterAvailableTools() {
    this.availableTools = new Map();
    this.tools.forEach((tool, name) => {
      if (this.permissionManager.hasPermission(name)) {
        this.availableTools.set(name, tool);
      }
    });
  }
}
```

### MCP 外部工具

通过 MCP 协议注册的外部工具，与内置工具共享同一套接口和权限体系。详见 [04-MCP协议](04-MCP协议.md)。

## 权限级别

| 级别 | 行为 | 自动/手动 | 示例工具 |
|------|------|-----------|----------|
| 只读（readonly） | 自动批准 | 自动 | Read、Grep、Glob、WebSearch |
| 修改（stateful） | 需用户审批 | 手动 | Edit、Write、NotebookEdit |
| 危险（dangerous） | 需特殊权限 | 手动 + 沙箱 | Bash、Agent |

## 权限模式

通过 `--permission-mode` 启动参数或 `settings.json` 配置：

| 模式 | 行为 | 适用场景 |
|------|------|----------|
| `default` | 每次工具调用都提示确认 | 首次使用、学习阶段 |
| `acceptEdits` | 文件编辑自动授权，命令执行需确认 | 日常开发 |
| `plan` | 仅规划，不执行任何修改 | 方案设计、代码审查 |
| `bypassPermissions` | 跳过所有弹窗 | CI/CD 等自动化环境 |

支持 `--allowedTools` 参数预授权无需确认的工具列表。

## 工具调用全流程

```
模型输出 tool_use
  ↓
ToolManager.filterAvailableTools()    # 权限过滤
  ↓
PermissionManager.hasPermission()     # 权限校验
  ↓
tool.inputSchema.parse(params)        # Zod Schema 校验
  ↓
┌─ 只读工具 → runToolsConcurrently()  # 并行执行
└─ 高危工具 → requestConfirmation()   # 用户确认
                ↓
             runToolsSerially()        # 串行执行
                ↓
             超时保护（120s）+ 输出截断（50KB）
                ↓
             ToolResult → 注入上下文
```
