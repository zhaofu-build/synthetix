# 对话式 AI 视频剪辑设计方案

## 一、功能概述

### 1.1 功能定义

通过自然语言对话完成视频剪辑任务，用户无需学习专业剪辑软件，只需描述想要的效果，AI 自动理解意图、规划方案、执行操作。

### 1.2 核心价值

| 价值点 | 说明 |
|--------|------|
| **零门槛** | 无需学习剪辑软件，自然语言交互 |
| **智能化** | AI 理解视频内容，自动推荐最佳方案 |
| **高效率** | 一句话完成复杂剪辑操作 |
| **可追溯** | 每一步操作都有记录，随时回退 |

### 1.3 目标用户

- 内容创作者（快速产出短视频）
- 营销人员（批量制作宣传视频）
- 普通用户（剪辑生活记录视频）

### 3.4 视频理解模块

**位置**: `src/application/services/video_understanding.py`

**职责**: 深度分析视频内容，为智能剪辑提供数据支撑

**处理流程**:

```
视频输入
    │
    ├─► 获取基础信息 (FFmpeg) → 时长/分辨率/帧率
    │
    ├─► 关键帧提取 (FFmpeg) → 每2秒或场景变化时提取
    │
    ├─► 视觉分析 (Qwen-VL) → 画面描述/对象检测/动作识别/情感
    │
    ├─► 语音转写 (Whisper) → 字幕文本
    │
    └─► 结果聚合 → 视频描述 + 精彩片段建议
```

**输出结构**:

```json
{
  "video_id": 123,
  "duration": 120.5,
  "resolution": [1920, 1080],
  "segments": [
    {
      "start": 0,
      "end": 15,

      "mood": "宁静",
      "quality_score": 0.85
    }
  ],
  "transcript": "今天的天气真好...",

    {"start": 15, "end": 30, "reason": "画面精彩，色彩丰富"}

```

```markdown
## 描述
自动识别口播视频中的有效片段，去除停顿和废话。

## 适用场景
- 知识讲解视频
- 产品介绍视频
- Vlog 口播部分

## 执行步骤

2. 提取语音转写文本

4. 生成剪辑方案
5. 执行剪辑

## 参数
- silence_threshold: 静音阈值（默认 0.5 秒）
- min_clip_duration: 最小片段时长（默认 2 秒）
```
