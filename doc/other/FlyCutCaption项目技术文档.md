# FlyCutCaption项目技术文档

## 概述

FlyCutCaption是一款由开发者x007xyz创建的开源视频字幕编辑工具，**将AI语音识别与视频剪辑功能无缝结合**，让用户能够通过"编辑字幕"来"剪辑视频"。与传统视频编辑工具需要手动定位时间轴不同，FlyCutCaption通过智能分析视频音频内容，自动生成带时间戳的字幕，用户只需删除不需要的字幕片段，系统会自动裁剪对应的视频部分并合成完整视频。**所有处理均在浏览器本地完成**，无需上传数据到服务器，兼顾隐私保护与高效处理。

**项目特点**：
- 开源免费（MIT协议）
- 完全浏览器本地运行，保障数据安全
- 支持多种视频/音频格式（MP4、MOV、AVI、WebM、MP3、WAV等）
- 基于OpenAI的Whisper模型实现高精度语音转文本
- 支持多语言识别（中、英等）
- 提供直观的可视化字幕编辑界面
- 实时同步视频预览，所见即所得
- 支持批量操作与撤销/重做功能
- 可自定义字幕样式（字体、颜色、位置、背景等）
- 支持导出SRT、VTT、JSON等字幕格式及处理后的视频
- 采用React 19 + TypeScript + Vite + Tailwind CSS技术栈
- 通过Hugging Face Transformers.js在浏览器本地运行AI模型
- 使用Web Workers实现后台AI处理，不阻塞主界面

## 核心技术实现

### 1. 语音识别模块

FlyCutCaption采用**OpenAI的Whisper模型**作为语音识别核心，通过Hugging Face Transformers.js在浏览器中本地运行。与传统服务端部署不同，这种架构具有以下优势：

**技术优势**：
- 零数据上传，保障隐私安全
- 支持多种语言识别（中、英等）
- 自动处理多声道音频
- 高精度时间戳生成
- 可选WebGPU加速（若设备兼容）
- 支持热词增强（如特定术语识别）

**工作流程**：
1. 用户上传视频文件或选择音频文件
2. 系统提取音频并标准化
3. 根据用户选择的语言加载对应的Whisper模型
4. 在Web Workers中执行语音识别，生成文本与时间戳
5. 生成带说话人ID的SRT字幕（若启用说话人分离）
6. 将字幕结果返回前端界面，供用户编辑

**代码逻辑片段**（基于浏览器JavaScript）：
```javascript
// 语音识别核心方法
async function analyzeAudio/video路径, 语言, 是否启用说话人分离) {
  // 1. 检查并加载模型
  if (!modelCache[语言]) {
    modelCache[语言] = await whisper.loadModel(语言);
  }

  // 2. 提取音频
  const audioData = await extractAudioFromVideo(视频路径);

  // 3. 在后台线程执行识别
  const result = await workerPool.execute('analyzeAudio', {
    audioData,
    language,
    returnSpkRes: 是否启用说话人分离
  });

  // 4. 生成SRT字幕
  const srtContent = generateSRT(result.text, result.timestamp, result.spk_ids);

  return srtContent;
}
```

### 2. 视频处理模块

视频处理模块是FlyCutCaption的另一核心技术，**通过WebAssembly封装FFmpeg**，实现浏览器中的视频剪辑与合成：

**技术实现**：
- 将FFmpeg编译为WebAssembly模块，实现浏览器本地调用
- 使用FileReader API读取本地视频文件
- 基于Canvas API实现视频预览
- 通过Web Audio API处理音频分析
- 使用Web Workers实现后台视频处理

**视频剪辑核心逻辑**：
```javascript
// 视频剪辑核心方法
async function clipVideo(原始视频路径, 保留的时间戳列表, 输出格式) {
  // 1. 生成临时文件夹
  const tempDir = await createTempDir();

  // 2. 为每个保留片段生成FFmpeg命令
  const commands = timeStamps列表.map((time, index) => {
    const start = time.start;
    const end = time.end;
    const duration = end - start;

    return `ffmpeg -ss ${start} -i "${原始视频路径}" -t ${duration} -c:v libx264 -crf 23 -c:a aac -b:a 128k "${tempDir}/clip_${index}.mp4"`;
  });

  // 3. 并行执行FFmpeg命令
  const promises = commands.map(cmd => workerPool.execute('runFFmpeg', cmd));
  await Promise.all(promises);

  // 4. 合并视频片段
  const clipFiles = await getClipFiles(tempDir);
  const concatCmd = generateConcatCommand(clipFiles, 输出格式);

  // 5. 执行合并命令并返回最终视频路径
  const outputVideoPath = await workerPool.execute('runFFmpeg', concatCmd);

  // 6. 清理临时文件
  await rimraf(tempDir);

  return outputVideoPath;
}
```

**字幕渲染实现**：
```javascript
// 字幕渲染核心方法
async function renderSubtitles(视频路径, 字幕内容, 字体样式配置) {
  // 1. 生成字幕文件
  const srtPath = await saveSRTToTemp(字幕内容);

  // 2. 构建FFmpeg字幕渲染命令
  const cmd = `ffmpeg -i "${视频路径}" -vf "drawtext=fontfile=${字体样式配置.fontFile}:textfile=${srtPath}:fontcolor=${字体样式配置.color}:fontsize=${字体样式配置(size)}:x=(w-tw)/2:y=h-th-20" -c:a copy "${tempDir}/with Subtitles.mp4"`;

  // 3. 执行命令并返回结果
  return await workerPool.execute('runFFmpeg', cmd);
}
```

## 视频剪辑/生成全流程逻辑

### 1. 视频上传与解析阶段

**输入处理**：
- 用户通过拖拽或点击选择上传本地视频文件
- 支持格式：MP4、MOV、AVI、WebM、MP3、WAV等
- 系统自动检测文件类型并解析基本信息（时长、分辨率等）

- 自动提取音频流
- 生成临时文件名存储到浏览器缓存
- 初始化处理进度条

### 2. AI语音识别与字幕生成阶段

**语音识别流程**：
1. 模型加载：根据用户选择的语言加载对应的Whisper模型
2. 音频处理：将视频音频转换为Whisper模型要求的格式
3. 语音转录：在后台Web Workers中执行语音识别
4. 时间戳生成：为转录文本添加精确的时间戳信息
5. 说话人分离：若启用，为不同说话人的语音段落分配唯一ID
6. 字幕格式转换：将识别结果转换为SRT/VTT格式

**说话人识别实现**（可选）：
```javascript
// 说话人识别核心方法
async function identifySpeakers(音频数据) {
  // 1. 检查并加载CAM++模型
  if (!modelCache.spkModel) {
    modelCache.spkModel = await campp.loadModel();
  }

  // 2. 执行说话人识别
  const spkResult = await modelCache.spkModel.generate(音频数据);

  // 3. 返回说话人ID列表
  return spkResult.spk_ids;
}
```

### 3. 字幕编辑与视频预览阶段

**编辑功能实现**：
- 字幕列表展示：按时间顺序展示识别出的字幕

- 批量操作：支持全选、批量删除、恢复删除等操作
- 实时预览：点击字幕片段可跳转到对应时间点
- 撤销/重做：支持编辑历史的回退与前进
- 字幕样式调整：实时修改字体、颜色、位置等样式并预览

**视频预览技术**：
- 使用HTML5 Video元素播放原始视频
- 基于Canvas API渲染编辑后的字幕效果
- 实时同步字幕编辑状态与视频播放位置
- 支持快捷键控制（空格播放/暂停，←/→快退/快进等）
- 提供"预览模式"，自动跳过已删除的字幕片段

### 4. 字幕样式定制与实时渲染阶段

**样式配置系统**：
- 字体设置：大小、粗细、颜色、字体选择
- 位置调整：上/中/下、左/中/右对齐

- 预设样式模板：经典白字、黑底白字等

**实时渲染技术**：

**导出流程**：
1. 用户选择导出选项（仅字幕/仅视频/字幕+视频）
2. 系统生成处理命令
3. 执行字幕渲染和/或视频剪辑
4. 处理进度实时反馈

- 字幕文件：SRT、VTT、JSON

**处理优化策略**：
- 根据设备性能自动调整处理参数

**访问方式**：
- 直接访问官网：`https://caption.flycut.co/`
- 无需注册或登录
- 无需下载或安装任何软件

**使用步骤**：

2. 拖拽视频文件到上传区域或点击选择文件
3. 选择识别语言（中文/英文/自动）
4. 点击"开始识别"，等待AI处理完成
5. 在识别结果界面编辑字幕，删除不需要的片段
6. 调整字幕样式（可选）
7. 点击"导出"按钮，选择导出格式并下载文件

**在线版限制**：
- 首次使用需下载模型（约200-500MB）
- 需要稳定的网络连接（模型下载和更新）
- 文件大小可能受限（通常不超过500MB）
- 处理大型视频可能需要较长时间

### 2. 本地部署（推荐高级用户）

**环境要求**：
- Node.js 18+版本

- 现代浏览器（Chrome/Firefox/Edge 85+或Safari 14+）

**部署步骤**：

- 适合处理大量或大型视频文件

### 3. 隐私与安全最佳实践

**数据安全策略**：
- **本地处理**：所有视频和音频处理均在用户设备上完成，不上传任何数据
- **浏览器缓存管理**：处理完成后自动清理浏览器缓存中的临时文件
- **模型安全**：模型通过HTTPS安全下载，验证完整性后缓存
- **隐私模式**：支持隐私模式，禁用所有可能的数据收集行为
- **自定义模型**：可部署私有模型服务器，避免依赖外部服务

**安全建议**：
- 使用HTTPS协议访问本地服务器
- 定期清理浏览器缓存中的临时文件
- 避免在公共网络环境下处理敏感内容
- 定期更新项目代码以获取最新安全补丁
- 对于企业部署，可配置私有CDN加速模型下载

### 4. 性能优化建议

**处理大型视频**：
- **分段处理**：对于超过30分钟的视频，建议分段处理
- **代理文件**：使用`--proxy_scale 0.5`参数生成代理文件提高处理速度
- **模型选择**：选择较小的Whisper模型（如`whisper-base`）提高处理速度
- **硬件加速**：启用WebGPU加速（若设备兼容）可提升处理速度2-3倍

**提升识别准确率**：
- **热词增强**：在识别设置中添加专业术语，提高特定领域识别准确率
- **音频质量**：确保输入视频音频清晰，减少背景噪音
- **采样率选择**：根据音频质量选择合适的采样率（通常16kHz-44.1kHz）
- **语言选择**：明确选择视频语言，避免自动检测错误

**导出优化**：
- **视频质量**：导出视频时根据需求选择合适质量（平衡文件大小与画质）

- **浏览器设置**：导出前确保浏览器设置允许下载，关闭不必要的标签页释放资源

## 常见问题与解决方案

### 1. 识别速度慢

**原因分析**：
- 设备性能不足
- 选择了过大的Whisper模型
- 网络不稳定导致模型下载慢
- 视频文件过大或分辨率过高
- 浏览器内存限制导致处理卡顿

**解决方案**：
- 更换较小的Whisper模型（如`whisper-base`）
- 调整`--proxy_scale`参数生成代理文件
- 确保网络稳定，或使用本地部署模式
- 分段处理大型视频
- 关闭不必要的浏览器标签页释放资源
- 使用支持WebGPU的浏览器（如Chrome 89+或Edge 91+）
- 确保系统有足够的内存（建议8GB以上）

### 2. 识别准确率低

**原因分析**：
- 选择了错误的语言模型
- 视频音频质量差或有大量背景噪音
- 专业术语或领域特定词汇识别困难
- 多说话人场景分离效果不佳
- 说话人声音特征差异小

**解决方案**：
- 明确选择视频语言，避免自动检测错误
- 使用音频增强工具预处理视频
- 添加专业术语到热词列表
- 调整说话人分离阈值
- 对于多说话人场景，先分离再分别处理
- 分段处理特别困难的段落
- 检查是否启用了说话人识别功能

### 3. 导出失败或卡顿

**原因分析**：
- 浏览器内存不足
- 视频时长过长（超过30分钟）
- 导出格式不支持
- 字幕样式配置错误
- FFmpeg WebAssembly模块异常

**解决方案**：
- 分段导出长视频
- 降低输出视频质量（如减小分辨率）
- 检查浏览器设置是否允许下载
- 简化字幕样式配置
- 更新浏览器到最新版本
- 清理浏览器缓存后重试
- 检查视频格式是否支持
- 避免在低内存设备上处理高分辨率视频
