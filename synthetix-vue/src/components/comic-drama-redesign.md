# 漫剧生成页面重构方案

## 现有流程问题分析

**当前 6 步线性流程**: 脚本 → 角色 → 分镜 → 音频 → BGM → 合成

| 问题 | 影响 |
|------|------|
| 系列管理冗余 | 大多数用户只想做一个漫剧，系列/集数概念增加认知负担 |
| 6 步太碎 | 音频和 BGM 不值得独立步骤，打断创作节奏 |
| 脚本/角色/分镜割裂 | AI 一次生成全部，却被拆成 3 个步骤来回跳 |
| 分镜没有独立上传 | 只能 AI 生成，用户无法用自己的图 |
| 左预览右编辑分离 | 左边只读预览和右边编辑互不关联，选分镜和编辑是分开的 |
| 手动保存按钮 | 应该自动保存 |

## 提议的新流程：3 页代替 6 步

```
┌─────────────────────────────────────────────────┐
│  故事   ←→   角色 & 场景   ←→   分镜 & 合成       │
│  (Page 1)     (Page 2)        (Page 3)           │
└─────────────────────────────────────────────────┘
```

### Page 1: 故事

```
┌──────────────────────────────────────────────────┐
│  项目名: [可编辑名称]        画风: [下拉]  类型: [下拉]  │
├──────────────────────────────────────────────────┤
│                                                    │
│  ┌────────────────────────────────────────────┐   │
│  │  故事描述                                    │   │
│  │  [大文本框: 描述你的漫剧故事...]               │   │
│  │                                              │   │
│  │  时长: [60s] 或 分镜数: [10]                  │   │
│  └────────────────────────────────────────────┘   │
│                                                    │
│  [✨ AI 生成脚本]  ← 主按钮，loading 状态           │
│                                                    │
│  ── 生成结果概览 ──────────────────────────────   │
│  标题: xxx                                         │
│  概要: xxx                                         │
│  角色: 3 个  分镜: 10 个  预计时长: 45s             │
│                                                    │
│  [进入角色设计 →]                                   │
└──────────────────────────────────────────────────┘
```

**关键改进**:
- **去掉系列**。打开页面直接进入故事编辑，没有系列选择页
- **去掉命名弹窗**。项目名直接内联编辑，默认 "未命名漫剧" + 时间戳
- AI 生成脚本后，自动把角色描述和分镜描述分别推到 Page 2 和 Page 3
- 底部导航到下一页，而非顶部步骤条

### Page 2: 角色 & 场景

```
┌──────────────────────────────────────────────────┐
│  ← 故事   角色 & 场景   分镜 →                      │
├────────────────────────┬─────────────────────────┤
│  角色 (3)   [+添加]     │  场景库   [+添加]         │
│                        │                          │
│  ┌──────────────────┐  │  ┌──────┐ ┌──────┐      │
│  │ [头像图/占位]     │  │  │ [图] │ │ [图] │      │
│  │                  │  │  │ 森林  │ │ 城市  │      │
│  │ 名字: 小明       │  │  └──────┘ └──────┘      │
│  │ 外貌: [可编辑]    │  │                          │
│  │ 性格: [可编辑]    │  │  ┌──────────────────┐   │
│  │ 音色: [可编辑]    │  │  │ 描述: [文本框]     │   │
│  │                  │  │  │ [AI生成] [上传图片] │   │
│  │ [AI生成图] [上传] │  │  └──────────────────┘   │
│  └──────────────────┘  │                          │
│  ┌──────────────────┐  │                          │
│  │ 角色卡片2...      │  │                          │
│  └──────────────────┘  │                          │
├────────────────────────┴─────────────────────────┤
│  [← 返回故事]                    [进入分镜 →]       │
└──────────────────────────────────────────────────┘
```

**关键改进**:
- **角色卡片** 展示头像图 + 名字，点击展开编辑
- 每个角色都有 **[AI 生成图]** 和 **[上传图片]** 两个按钮并排
- **场景库** 是新概念 — 用户可以预先创建场景背景图（森林、城市、室内等）
  - 场景图同样支持 AI 生成 + 上传
  - 分镜可以引用场景图，保持背景一致性
- 所有修改自动保存（debounce），不显示"保存"按钮

### Page 3: 分镜 & 合成

```
┌──────────────────────────────────────────────────┐
│  ← 角色   分镜 & 合成                               │
├─────────────────────┬────────────────────────────┤
│                     │  分镜 #3 编辑                │
│  分镜网格            │  ┌────────────────────┐     │
│  ┌─────┐ ┌─────┐   │  │ 场景描述:            │     │
│  │ #1  │ │ #2  │   │  │ [可编辑文本]         │     │
│  │ [图]│ │ [图]│   │  │                    │     │
│  │ 3s  │ │ 5s  │   │  │ 图片:               │     │
│  └─────┘ └─────┘   │  │ [当前图预览]         │     │
│  ┌─────┐ ┌─────┐   │  │ [AI生成] [上传] [↻]  │     │
│  │>#3< │ │ #4  │   │  │                    │     │
│  │ [图]│ │ --- │   │  │ 时长: [3s] 转场: [>]  │     │
│  │ 4s  │ │ 3s  │   │  │ 情绪: [下拉]         │     │
│  └─────┘ └─────┘   │  │                    │     │
│  ┌─────┐ ┌─────┐   │  │ 对白:               │     │
│  │ ... │ │ + 添加│  │  │ 小明: "你好！" [生成] │     │
│  └─────┘ └─────┘   │  │ 旁白: "他走了" [生成] │     │
│                     │  │                    │     │
│  总时长: 45s         │  │ 视频: [生成片段] [↻]  │     │
│                     │  │ [▶ 播放预览]         │     │
│                     │  └────────────────────┘     │
├─────────────────────┴────────────────────────────┤
│  BGM: [选择] 🔊 音量 [---●---]                     │
│  [🎵 合成漫剧视频]                                  │
│  ── 已有输出 ──                                    │
│  [▶ 视频1]  [▶ 视频2]                              │
└──────────────────────────────────────────────────┘
```

**关键改进**:
- **左右分栏**: 左侧分镜网格（缩略图 + 时长），右侧选中分镜的详细编辑
- **每个分镜独立**: 选哪个编哪个，互不干扰
- **图片三按钮**: AI 生成 / 上传 / 重新生成（不满意就换）
- **音频内联**: 对白的语音生成直接在分镜编辑里，不单独一步
- **视频片段独立**: 每个分镜单独生成视频片段，可预览
- **BGM + 合成合并到底部**: 不再是独立步骤，而是本页底部的操作区
- **输出历史**: 已合成的视频列表，可回放

### 整体交互变化总结

| 维度 | 现在 | 改进后 |
|------|------|--------|
| 页面/步骤 | 6 步线性 + 系列管理 | 3 页自由切换 |
| 系列管理 | 必须经过 | 完全去掉 |
| 创建流程 | 命名弹窗 → 系列 → 项目 | 直接进入故事页开始写 |
| 角色图片 | 只有上传+AI生成 | 上传 + AI生成 + 重生成 |
| 分镜图片 | 只有AI生成 | 上传 + AI生成 + 重生成 |
| 场景/背景 | 无 | 新增场景库，分镜可引用 |
| 音频生成 | 独立步骤 | 内联在分镜编辑中 |
| BGM | 独立步骤 | 合并在分镜页底部 |
| 保存 | 手动保存按钮 | 自动保存 (debounce) |
| 分镜预览 | 与编辑分离 | 左右分栏，点选即编辑 |

## 实施计划

### 前端文件变更

1. **新建** `ComicStory.vue` — Page 1 故事页（脚本输入 + AI 生成）
2. **新建** `ComicCast.vue` — Page 2 角色 & 场景页
3. **新建** `ComicStoryboard.vue` — Page 3 分镜 & 合成页
4. **重写** `ComicDrama.vue` — 简化为 3 页容器 + 页面切换导航
5. **删除** `ComicPanel.vue` — 逻辑合并到 ComicStoryboard
6. **删除** `ComicAudio.vue` — 逻辑合并到 ComicStoryboard
7. **删除** `ComicPanel.vue` 不删除，保留但不再被主页面引用

### 后端

基本复用现有 API，不需要新增接口。场景库可暂存为特殊角色（type=scene），后续再独立。
