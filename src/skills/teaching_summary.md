# 教学视频摘要
从教学/课程视频中提取核心知识点，生成精简的教学摘要视频。
**所需工具**: transcribe_video, analyze_transcript, cut_video, merge_videos
**适用场景**: 在线课程、培训视频、讲座、教程
**参数**: target_duration(摘要时长, 默认120秒), density(信息密度: 高/中/低, 默认中)

## 执行流程

1. 使用 transcribe_video 转录完整课程内容
2. 分析转录文本：
   - 识别知识点和概念定义
   - 标记例题和演示
   - 提取总结性段落
3. 按 density 筛选片段：
   - 高密度：仅保留核心概念定义和关键结论
   - 中密度：核心概念 + 重要例题
   - 低密度：核心概念 + 例题 + 补充说明
4. 使用 cut_video 提取选中片段
5. 使用 merge_videos 合并为连贯摘要

## 剪辑策略

- 保留每个知识点的完整讲解（不切断句子中间）
- 优先保留有视觉演示配合的讲解
- 删除过渡、寒暄、重复解释
- 确保知识点之间有逻辑连贯性
