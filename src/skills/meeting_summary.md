# 会议纪要提取
从会议/访谈视频中提取关键决策、讨论要点和结论，生成结构化纪要。
**所需工具**: transcribe_video, analyze_transcript, cut_video
**适用场景**: 会议录像、访谈、讲座、讨论会
**参数**: target_duration(目标摘要时长, 默认180秒), language(语言, 默认zh)

## 执行流程

1. 使用 transcribe_video 获取完整转录文本
2. 分析转录文本，识别以下要素：
   - 关键决策和结论
   - 重要讨论要点
   - 行动项和负责人
   - 时间节点和截止日期
3. 使用 cut_video 提取包含关键内容的时间段
4. 将提取的片段按逻辑顺序组合
5. 生成结构化纪要文本

## 提示策略

- 优先保留包含明确决策和行动项的片段
- 删除寒暄、重复讨论、跑题内容
- 保留发言人转换的上下文
- 确保最终时长在 target_duration 范围内
