# Claude Code 源码技术分析 — 总览与导读

## 背景

Claude Code 是 Anthropic 推出的 AI 编程助手，其 51.2 万行 TypeScript 源码通过 npm 包的 source map 文件意外泄露（2026年3月31日）。深度分析表明，Claude Code 并非简单的"聊天机器人"，而是一个高度工程化的 **Agent Operating System（智能体操作系统）**，通过精心设计的多 Agent 协作、工具系统、上下文管理和执行管道，实现了从代码理解到自主执行的完整闭环。

本文档系列共 13 篇（00-12），从系统架构到底层实现逐步展开，全面剖析 Claude Code 的核心技术设计。第 12 篇为 synthetix 项目自身的架构详解。

## 核心设计理念

### 1. 笨引擎 + 聪明模型

运行时不包含业务逻辑，只做**状态管理**和**执行编排**。所有智能决策由 Claude 模型完成，运行时代码随着模型能力提升自动增强，无需修改。这正是 Claude Code 能在模型迭代后"免费"变强的根本原因。

### 2. 安全优先

六级权限验证链 + OS 级沙箱（macOS Seatbelt）+ 防蒸馏保护。任何层级的 `deny` 规则具有最高优先级，不会被覆盖。沙盒功能使权限提示减少 84%，兼顾安全与体验。

### 3. 标准化扩展

通过 MCP 协议统一工具接入标准，Skill/Plugin/Hook 三层扩展机制满足不同粒度的定制需求。MCP 的 Host-Client-Server 三角色模型，使 Claude Code 能无缝连接外部工具生态。

### 4. 上下文工程

五级压缩 + 三层记忆架构，系统性解决模型上下文窗口限制。`snipCompression` 算法保留语义连续性，使用户可以在一个会话中连续工作数小时而不丢失关键信息。

## 技术栈

| 层面 | 技术 | 作用 |
|------|------|------|
| 运行时 | **Bun** | 高性能 JS/TS 执行环境，支持死代码消除 |
| 语言 | **TypeScript（严格模式）** | 类型安全，Zod v4 运行时校验 |
| 终端 UI | **React + Ink** | 在终端中渲染 React 组件 |
| AI API | **@anthropic-ai/sdk** | 调用 Claude 大模型（Opus/Sonnet） |
| 参数校验 | **Zod v4** | 工具输入参数 Schema 定义与校验 |
| 工具协议 | **MCP SDK** | 模型与外部工具的标准化通信 |
| 代码智能 | **LSP** | 语言服务器协议，跳转定义/查找引用 |
| 代码解析 | **tree-sitter** | 语法树解析，依赖图构建 |
