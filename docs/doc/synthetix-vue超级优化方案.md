# Synthetix-Vue 前端超级优化方案

> 基于后端超级优化方案，对 synthetix-vue 前端所有页面、组件、交互进行全面重新设计。

---

## 一、当前前端架构总览

| 路由 | 组件 | 功能 |

| `/editor` | `UnifiedEditor.vue` | 主编辑器（欢迎页 + 编辑布局） |

TTS / ASR / VL / VoiceCloning / ComfyUIAudio / AudioProcessing / VideoProcessing / ComicDrama / SystemSetting / TaskCenter / McpManager / ExtensionManager / KnowledgeBase / SystemStatus

## 二、整体布局重设计

### 2.1 统一编辑器布局升级

**现状**：三栏布局（左工作区 + 中 AI 对话 + 右素材/预览），布局预设仅三种。

**重设计方向**：借鉴专业 NLE 编辑器（Premiere / DaVinci Resolve）的多面板可自由编排理念，同时保留 AI 对话驱动的特色。

**具体方案**：

#### 面板体系扩充
将当前的固定三栏扩展为 **6 个可编排面板**，用户可自由组合：

| 面板 | 来源 | 状态 |
|------|------|------|
| AI 对话栏 | 现有 ChatSidebar | 升级 |
| 剪辑方案 | 现有 ClipPlanPanel | 升级 |
| 素材库 | 现有 MaterialsPanel | 升级 |
| 视频预览 + 时间线 | 现有 PreviewPanel | **大幅重写** |
| 音频工作站 | 现有 AudioPanel | 升级 |
| 字幕编辑器 | **全新** | 新增 |

#### 布局预设系统
提供 6 种预设布局，用户可保存自定义布局：

1. **默认模式**（当前布局优化版）：左工作区 + 中 AI 对话 + 右素材/预览
2. **剪辑师模式**：上方大时间线 + 左素材库 + 右预览 + 底部 AI 对话
3. **对话模式**：AI 对话居中大面板 + 右侧缩略预览
4. **预览模式**：视频预览占主体 + 底部时间线 + 侧边 AI 对话
5. **字幕模式**：字幕编辑器居中 + 左侧视频预览 + 右侧 AI 对话
6. **自由模式**：所有面板可拖拽到任意位置（未来目标）

#### 全局交互增强
- **底部状态栏**（新增）：显示当前项目名、素材数量、AI 模型状态、渲染状态、内存/CPU 使用率
- **迷你地图**（时间线面板内）：缩略显示整体时间线，可快速跳转
- **全局搜索**（增强现有）：支持搜索素材、项目、工具、设置项、快捷键
- **面包屑导航**（增强）：在编辑器模式下显示 "项目 > 剪辑方案 > 片段详情" 等层级

### 2.2 主导航栏重设计

**现状**：顶部固定导航栏，包含文件菜单、工具菜单、设置链接。

**重设计方向**：

#### 顶部导航栏结构
```
[Logo Synthetix] | [文件] [编辑] [视图] [工具] [帮助] | [项目名称 ✏️] | [全局搜索 🔍] | [主题 🌙] [通知 🔔] [设置 ⚙️]
```

#### 新增菜单功能
- **文件菜单**（增强）：
  - 新建项目 → 弹出模板选择器（短视频/Vlog/教学/产品展示/空白项目）
  - 打开项目 → 项目列表弹窗（支持搜索、排序、缩略图预览）
  - 保存项目（Ctrl+S）
  - 导出项目 → 选择导出格式和目标平台
  - 项目模板管理 → 保存/加载/删除自定义模板
  - 最近项目列表

- **编辑菜单**（新增）：
  - 撤销（Ctrl+Z）/ 重做（Ctrl+Y）
  - 剪辑操作历史面板
  - 偏好设置（用户级配置）

- **视图菜单**（新增）：
  - 布局预设切换（6 种预设）
  - 面板显示/隐藏切换
  - 全屏模式切换（F11）
  - 缩放控制

- **工具菜单**（增强）：
  - 最近使用的工具（保留现有逻辑）
  - 按分类展示：AI 工具、音频工具、视频工具、系统工具
  - 工具搜索（输入关键词快速定位）

- **帮助菜单**（新增）：
  - 快捷键列表
  - 使用文档
  - 检查更新
  - 关于

#### 通知系统（新增）
- 顶部导航栏右侧增加通知铃铛图标
- 通知类型：渲染完成、任务失败、系统警告、AI 调用异常
- 点击展开通知面板，支持标记已读和一键清除

## 三、核心面板重设计

### 3.1 视频预览 + 时间线面板（PreviewPanel 大幅重写）

**现状**：PreviewPanel 集成了视频播放器、时间线条和渲染功能，但时间线功能较弱，仅能显示剪辑方案片段。

**重设计方向**：借鉴专业 NLE 的多轨时间线，同时保持 AI 驱动的简洁风格。

#### 时间线系统重设计

**多轨时间线**（核心新增）：
- **视频轨**：显示素材片段，支持拖拽排序、缩放、吸附
- **音频轨**（1-3 条）：显示音频波形，支持独立编辑
- **字幕轨**（1-2 条）：显示字幕块，可拖拽调整时间点
- **标记轨**：显示 AI 标记的高光片段、静音段、场景切换点

**时间线交互**：
- **缩放**：鼠标滚轮缩放时间线精度（帧级 → 分钟级）
- **拖拽**：拖拽片段调整位置和时长
- **吸附**：片段边缘自动吸附到相邻片段或标记点
- **选区**：框选多个片段批量操作
- **播放头**：红色竖线标记当前播放位置，与视频预览同步
- **迷你导航条**：顶部缩略条显示整个视频，可快速跳转

**时间线与 AI 对话联动**：
- AI 建议剪辑操作时，时间线上用虚线框标注建议区域
- 用户确认前可在时间线上调整建议的范围
- 工具执行后，时间线实时更新显示操作结果
- 右键时间线片段 → "让 AI 分析这段" → 自动触发上下文相关的 AI 分析

**视频预览增强**：
- **双屏对比**：原始素材 vs 剪辑后效果
- **逐帧预览**：左右箭头逐帧步进
- **AB 对比**：渲染前后对比（渲染完成时自动弹出对比视图）
- **画中画预览**：小窗口浮层预览，不遮挡编辑区域
- **标注模式**：用户可在预览画面上直接画框、标注，标注自动转为 AI 对话的上下文

#### 渲染面板增强

**渲染设置**（增强现有）：
- 目标平台选择（抖音/B站/YouTube/小红书/自定义）
- 根据平台自动填充推荐参数（分辨率、码率、帧率、时长上限）
- 显示预估文件大小和渲染耗时
- 代理渲染选项（低质量快速预览 vs 全质量导出）

**渲染进度面板**（重设计）：
- 整体进度条 + 各阶段子进度（分析 → 剪辑 → 合成 → 编码）
- 实时预览当前渲染帧
- 预估剩余时间
- 渲染完成后自动弹出通知和预览

### 3.2 字幕编辑器面板（全新）

**来源**：对应后端优化方案 3.1 "编辑文本即编辑视频"和 3.4 "说话人感知剪辑"。

**核心功能**：

#### 字幕列表视图
- 以文本列表形式展示 ASR 转录结果
- 每条字幕显示：时间戳、说话人标识（彩色标签）、文本内容
- 支持直接编辑文本内容（双击进入编辑模式）
- 支持删除字幕条目（对应视频片段被标记为删除）
- 支持合并相邻字幕（拖拽或按钮）
- 支持拆分字幕（光标定位 → 拆分按钮）

#### 说话人面板
- 说话人列表，每个说话人用不同颜色标识
- 支持为说话人添加自定义名称（如"主持人"、"嘉宾A"）
- 按说话人筛选字幕
- 按说话人批量剪辑：一键提取/删除某说话人的所有片段
- 说话人统计：每个说话人的发言时长、片段数

#### 字幕搜索与导航
- 全文搜索字幕内容，高亮匹配结果
- 搜索结果列表，点击跳转到对应时间点
- 时间轴缩略导航条（显示字幕密度热力图）

#### 字幕样式编辑器
- 实时预览的字幕样式配置：
  - 字体、字号、颜色、描边、阴影
  - 位置（上/中/下，可微调坐标）
  - 背景（颜色、透明度、圆角）
- 预设模板库（抖音风格/B站风格/极简/花字等）
- 自定义样式保存为模板
- 每个说话人可配置不同字幕样式

#### 字幕与视频联动
- 点击字幕条目 → 视频预览跳转到对应时间点
- 删除字幕条目 → 时间线上对应片段标记为"待删除"（红色）
- 选中多个字幕 → 右键"合并为一段" → 自动合并视频片段
- 字幕时间点可在时间线上拖拽微调

### 3.3 AI 对话栏增强（ChatSidebar 升级）

**现状**：ChatSidebar 已支持 SSE 流式、工具调用卡片、确认面板、快捷操作、右键菜单、Markdown 渲染。功能较为完整。

**增强方向**：

#### 对话模式切换
在对话栏顶部增加模式切换标签：
- **自由对话**（当前模式）：自然语言交流
- **剪辑方案**（新增）：Agent 自动规划完整剪辑方案，展示为可编辑的操作列表
- **深度研究**（增强）：三阶段深度研究过程的可视化展示

#### 剪辑方案模式
- Agent 规划完成后，以卡片列表形式展示每个操作：
  - 操作类型图标（剪切/拼接/添加字幕/调整音频等）
  - 操作描述（"在 00:01:23 处剪切，保留 00:00:00-00:01:23 片段"）
  - 时间线预览（缩略条标注操作位置）
  - 风险标签（safe / 需确认 / destructive）
- 用户操作：
  - 逐一确认/拒绝每个操作
  - 批量确认所有安全操作
  - 拖拽调整操作顺序
  - 编辑操作参数（点击操作卡片展开参数面板）
- 确认后显示执行进度（每个操作的状态：等待/执行中/完成/失败）

#### 工具调用卡片增强
- 显示工具执行耗时
- 显示 AI 模型消耗的 Token 数量（可折叠）
- 失败时显示详细错误信息和重试按钮
- 视频处理工具显示进度条
- 支持"查看 FFmpeg 命令"折叠面板

#### 快捷操作增强
- 根据当前上下文动态推荐操作：
  - 选中素材后 → "分析此素材" / "智能剪辑" / "提取音频"
  - 查看剪辑方案后 → "调整方案" / "添加转场" / "预览效果"
  - 渲染完成后 → "导出" / "发布到平台" / "生成元数据"
- 支持用户自定义快捷操作（保存常用指令组合）

#### 对话历史增强
- 对话历史搜索（全文搜索历史消息）
- 按日期筛选对话
- 标记重要对话为"收藏"
- 导出对话记录为 Markdown

### 3.4 素材库面板增强（MaterialsPanel 升级）

**现状**：支持列表/网格视图、搜索、拖拽上传、批量操作、素材详情。

**增强方向**：

#### 素材分析状态
每个素材卡片增加分析状态指示器：
- 未分析（灰色）→ 分析中（旋转动画）→ 已分析（绿色）
- 分析完成显示：时长、分辨率、有无字幕、说话人数、内容标签
- 一键批量分析所有未分析素材

#### 智能分类
- 按内容类型自动分类：人物、风景、产品、教学、运动等
- 按质量等级分类：高光片段、普通片段、低质量片段
- 按情感分类：积极、中性、消极
- 分类标签可筛选

#### 素材推荐
- 基于当前剪辑方案，AI 推荐可能需要的素材
- "素材不足提醒"：剪辑方案需要 N 个片段但素材库只有 M 个时自动提醒
- 推荐素材来源：在线素材库搜索（对接 Pexels/Pixabay API）

#### 素材详情面板增强
- 增加视频关键帧缩略条（在详情面板底部展示）
- 增加音频波形可视化
- 增加字幕预览（如果有转录结果）
- 增加"相似素材"推荐

#### 素材导入增强
- 支持从 URL 直接导入（YouTube/B站链接）
- 支持批量拖拽导入（保留现有）
- 导入时可选自动分析（ASR + 元数据提取）
- 导入进度可视化（多文件并行导入进度）

### 3.5 音频工作站面板（AudioPanel 升级）

**现状**：TTS 语音合成 + BGM 选择，功能较基础。

**增强方向**：

#### 音频波形可视化
- 显示当前视频的音频波形图
- 在波形上标注：静音段（灰色）、高音量段（红色高亮）、语音段（绿色）、音乐段（蓝色）
- 支持在波形上直接选区操作（选中静音段 → 删除）

#### 音频编辑功能
- 音量曲线编辑（包络线）：可视化调整不同时间点的音量
- 淡入淡出控制：拖拽设置淡入淡出范围
- 音频片段裁剪：在波形上选择范围 → 裁剪
- 多音轨混合可视化：视频原声 + TTS + BGM 的轨道叠加视图

#### TTS 增强
- 说话人风格预设（新闻播报/轻松对话/有声书/教学等）
- 情感参数调节（平静/激动/悲伤/欢快）
- 语速微调滑块（0.5x - 2.0x）
- 试听片段选择（只试听选中的字幕片段而非全部）
- 批量 TTS：选中多段字幕 → 批量生成语音

#### BGM 增强
- AI 推荐 BGM（基于视频内容分析推荐匹配风格的音乐）
- BGM 情绪标签筛选（欢快/悲伤/紧张/轻松/史诗/电子等）
- BGM 节拍可视化（在时间线上显示节拍标记，辅助对齐剪辑点）
- BGM 自动淡出（视频结尾自动淡出背景音乐）
- 多段 BGM（支持在不同片段使用不同的 BGM）

### 3.6 剪辑方案面板增强（ClipPlanPanel 升级）

**现状**：支持创意描述、目标时长、风格选择、生成方案、可视化时间线、拖拽排序、撤销重做。

**增强方向**：

#### 方案模板库
- 预置剪辑方案模板：
  - 短视频高光（60 秒精华）
  - 教学摘要（提取知识点）
  - 产品展示（功能亮点）
  - 会议纪要（发言摘要）
  - Vlog 精选（高光片段拼接）
- 每个模板预填创意描述、目标时长、风格标签
- 用户可保存自定义模板

#### 片段增强
- 每个片段卡片显示：
  - 缩略图（提取关键帧）
  - 时间范围（起止时间 + 时长）
  - 来源素材名称
  - 内容标签（AI 自动标注）
  - 说话人标签（如有）
  - 音频波形缩略图
- 片段编辑对话框增强：
  - 精确时间输入（时:分:秒.毫秒）
  - 缓冲区设置（margin_before / margin_after）
  - 转场效果选择（硬切/淡入淡出/交叉溶解/滑动）
  - 速度调节（0.25x - 4.0x）

#### 方案对比视图
- "原始方案" vs "修改后方案"的对比展示
- 高亮显示变更的片段（新增/删除/调整的用不同颜色）
- 版本历史（每次修改保存为版本快照，可回退）

## 四、新增页面/面板

### 4.1 欢迎页重设计（UnifiedEditor 未加载项目时）

**现状**：显示项目创建卡片 + 项目列表（按时间分组）。

**重设计方向**：

#### 项目创建流程
- 首页展示大型"创建项目"入口，提供 3 种创建方式：
  1. **从模板创建**：选择预设模板 → 填写项目名称 → 自动配置参数
  2. **从素材创建**：拖入视频文件 → 自动分析 → 推荐剪辑方案
  3. **空白项目**：仅命名，进入编辑器后手动操作

#### 模板选择器
- 卡片网格展示所有可用模板
- 每个模板卡片包含：名称、描述、预览图、适用场景标签
- 模板分类：短视频 / Vlog / 教学 / 产品 / 会议 / 自定义
- 点击模板 → 右侧展示详情和配置项

#### 项目列表增强
- 保留时间分组（今天/昨天/更早）
- 增加卡片式展示（每个项目卡片显示缩略图、名称、最近修改时间、素材数量）
- 增加网格/列表视图切换
- 增加搜索和筛选（按类型、日期范围）

## 十二、性能优化

### 12.1 组件懒加载

**现状**：MainLayout 中 12 个弹窗工具已使用 `defineAsyncComponent` 懒加载。

**增强方向**：
- 路由级代码分割（当前路由组件应使用 `() => import()` 懒加载）
- 大型子面板（时间线、字幕编辑器）使用 `defineAsyncComponent`
- 重量级依赖（如波形可视化库）按需加载

### 12.2 虚拟列表

**应用场景**：
- 素材列表（可能数百条）
- 字幕列表（可能数千条）
- 任务列表
- 知识库条目列表

使用 `el-table` 的虚拟滚动或引入 `vue-virtual-scroller`。

### 12.3 时间线渲染优化

- 仅渲染可见区域的片段（虚拟滚动应用于时间线）
- 片段缩略图使用 Intersection Observer 懒加载
- 波形图使用 Canvas 渲染（非 DOM 元素）
- 缩放时使用节流（throttle）避免频繁重绘

### 12.4 缓存策略

- 素材元数据前端缓存（Pinia store + localStorage 持久化）
- 翻译结果缓存（同一字幕不重复请求 AI）
- 项目配置缓存（减少不必要的 API 调用）

## 总结

本前端优化方案从后端超级优化方案中提炼出所有需要前端配合的功能点，系统性地规划了 **4 个全新面板、10 个通用组件、4 个 Store 模块、4 个 API 模块、5 个 Composable** 的设计与实现。

**核心理念**：
1. **时间线为中心**：多轨时间线是专业视频编辑器的核心，将 Synthetix 从"AI 对话工具"提升为"AI 驱动的专业编辑器"
2. **文本即操作**：字幕编辑器让用户以文本编辑的方式操作视频，与 AI 对话形成互补的交互模式
3. **可视化一切**：AI 决策、FFmpeg 命令、音频波形、质量报告全部可视化，降低用户认知负担
4. **渐进式增强**：每个新增面板独立可用，不依赖其他面板的完成，按优先级逐步交付
