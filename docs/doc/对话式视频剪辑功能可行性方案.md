# 对话式视频剪辑功能可行性方案

## 一、功能概述

### 1.1 功能定义

在现有 Synthetix 平台上新增**对话式视频剪辑**功能，用户通过自然语言对话完成视频编辑任务，无需手动操作复杂的剪辑软件。

### 1.2 核心能力

| 能力 | 说明 |
|------|------|
| 自然语言理解 | 解析用户的剪辑意图，如"把前30秒剪出来" |
| 多轮对话交互 | 上下文记忆、追问澄清、方案修改 |
| 视频内容理解 | 通过视觉语言模型分析视频画面和内容 |
| 智能剪辑规划 | 根据文案自动规划剪辑方案 |
| 一键执行渲染 | 自动调用 FFmpeg 完成视频处理 |

### 1.3 用户价值

- **降低门槛**：无需学习专业剪辑软件
- **提高效率**：一句话完成复杂剪辑操作
- **智能推荐**：AI 自动分析素材并推荐最佳方案

## 四、核心模块设计

### 4.1 对话管理 Agent

**职责**：管理对话会话、识别用户意图、收集必要参数、控制执行流程

**核心组件**：

| 组件 | 功能 |
|------|------|
| SessionManager | 创建/销毁会话，管理会话超时 |
| IntentRecognizer | 使用 LLM 识别用户意图类型 |
| SlotFiller | 从对话中提取必要参数（视频ID、时间等） |
| DialogStateMachine | 管理对话状态流转 |

**支持的意图类型**：

| 意图 | 说明 | 必填参数 |
|------|------|----------|
| cut_video | 剪切视频 | video_id, start_time/end_time |
| merge_videos | 合并视频 | video_ids |
| add_subtitle | 添加字幕 | video_id, subtitle_content |
| add_audio | 添加音频 | video_id, audio_source |
| change_speed | 调整速度 | video_id, speed_factor |
| smart_clip | 智能剪辑 | description, duration |
| analyze_video | 分析视频 | video_id |
| generate_video | AI生成 | prompt |

### 4.2 视频理解模块（增强现有 Qwen-VL）

**职责**：深度分析视频内容，为智能剪辑提供数据支撑

**处理流程**：

```
视频输入
    │
    ▼
┌─────────────┐
│ 获取基础信息 │  → 时长、分辨率、帧率、编码格式
└─────┬───────┘
      │
      ▼
┌─────────────┐
│ 关键帧提取  │  → 按间隔(2秒)或场景变化提取帧
└─────┬───────┘
      │
      ▼
┌─────────────┐
│ VLM 分析    │  → 调用 Qwen3-VL 分析每帧内容
└─────┬───────┘      - 画面描述
      │              - 对象检测
      │              - 动作识别
      │              - 情感基调
      ▼
┌─────────────┐
│ 语音转写    │  → 调用 Whisper 提取字幕
└─────┬───────┘
      │
      ▼
┌─────────────┐
│ 结果聚合    │  → 生成视频描述 + 精彩片段建议
└─────────────┘
```

**输出结构**：

```json
{
  "duration": 120.5,
  "resolution": [1920, 1080],
  "segments": [
    {
      "start_time": 0,
      "end_time": 10,
      "description": "海边日出场景",
      "mood": "宁静",
      "quality_score": 0.85
    }
  ],
  "transcript": "字幕文本...",
  "suggested_highlights": [
    {"start": 15, "end": 30, "reason": "画面精彩"}
  ]
}
```

### 4.3 智能剪辑规划器

**职责**：根据用户描述和素材信息，生成完整剪辑方案

**输入**：
- 用户描述（自然语言）
- 可用素材列表（含分析结果）
- 目标时长
- 风格偏好

**输出**：
- 片段列表（来源、起止时间）
- 转场效果
- 背景音乐建议
- 字幕时间轴

### 4.4 工具注册表

**职责**：统一管理所有可调用的工具，供 Agent 选择执行

**工具列表**：

| 工具名 | 功能 | 对应现有模块 |
|--------|------|--------------|
| cut_video | 剪切视频 | ffmpeg_adapter |
| merge_videos | 合并视频 | ffmpeg_adapter |
| add_subtitle | 添加字幕 | ffmpeg_adapter |
| add_audio | 添加音频 | ffmpeg_adapter |
| change_speed | 调整速度 | ffmpeg_adapter |
| analyze_video | 分析视频 | qwen_vl_adapter |
| transcribe_audio | 语音转写 | whisper_adapter |
| generate_tts | 语音合成 | fish_speech_adapter |
| download_material | 下载素材 | video_downloader_adapter |

## 十一、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| LLM 意图识别不准确 | 用户体验差 | 多轮确认 + 置信度阈值 |
| 视频分析耗时长 | 响应慢 | 异步处理 + 进度提示 + 缓存 |
| 长视频处理内存溢出 | 系统崩溃 | 分段处理 + 流式处理 |
| FFmpeg 命令执行失败 | 任务中断 | 错误捕获 + 回滚机制 |
| 并发会话过多 | 性能下降 | 会话数量限制 + 队列管理 |

## 十二、总结

本方案基于 Synthetix 现有架构，复用已有的 LLM、VLM、FFmpeg、Whisper 等核心能力，通过新增对话管理 Agent 模块实现自然语言视频剪辑功能。

**核心优势**：
1. **复用度高**：80% 能力可直接复用现有模块
2. **扩展性好**：模块化设计，易于添加新意图和工具
3. **实现周期短**：预计 4-6 周完成核心功能
4. **用户体验佳**：自然语言交互，降低使用门槛

**关键里程碑**：
- Week 2：完成基础对话框架，可进行简单剪辑
- Week 4：完成视频理解增强，支持智能分析
